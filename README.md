# Colab Experiments

A small collection of exploratory Google Colab notebooks and machine-learning experiments.

## Status

This is a sandbox/prototype repository rather than a maintained research release. Individual notebooks may use different datasets, dependencies, or runtime assumptions.

## Usage

1. Open the required notebook in Google Colab.
2. Review its dependency installation cells and data paths.
3. Use a separate output directory for generated datasets and checkpoints.
4. Record the random seed and notebook revision when results are reused.

Do not store credentials, private datasets, unpublished result bundles, or large generated artifacts here. Promote reusable implementations into a dedicated project repository once their scope is stable.
